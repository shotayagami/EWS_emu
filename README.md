# EWS音声信号エミュレータ

Python標準ライブラリだけで動作するWindows GUIです。開始信号（第一種/第二種）と終了信号を生成し、48 kHz・16-bit・モノラルPCMのWAVに保存します。

## 起動

```powershell
python .\ews_emu.py
```

画面で信号種別、地域、送出日時、媒体、ブロック数、保存先を指定します。地域は総務省告示第405号の地域共通・広域・都道府県からドロップダウンで選びます。音声FSKモードでは上段の全体波形で範囲を選び、下段に送信ビット列とPCM波形を表示します。上段の枠外をクリック/ドラッグすると枠がその位置へ幅を保ったまま移動し、枠内のドラッグでも移動できます。端をドラッグすると幅を調整できます。横移動できる場所では左右矢印カーソルを表示します。「全体表示」で全送出時間に戻り、ホイールでも拡大縮小できます。「再生」で生成音声を確認し、「生成・保存」で48 kHz・16-bit・モノラルPCM WAVを出力します。

「地上デジタル記述子」モードでは、選択地域に対応する架空のデモ用サービスIDと局名を選び、緊急情報記述子（tag `0xFC`）をプレビューして`.bin`に保存できます。デモ値は実際の放送サービスを表さず、実放送や実機試験には使用できません。記述子は開始/終了、第一種/第二種、地域符号を含みます。MPEG-2 TS/PMTへの多重、TMCC起動フラグ、RF変調は生成しません。このモードでは音声再生できません。

- 開始信号: テレビ・FMは4ブロック以上、中波・短波は10ブロック以上
- 終了信号: テレビ・FMは2ブロック以上、中波・短波は4ブロック以上
- 開始・終了とも先頭に1秒の無信号を付けます。終了信号では各100-bitブロックの後に92-bit分の無音を付けます。
- 「試験信号（第一種/第二種）」は音声FSKでは終了信号と同じ符号を生成します。地上デジタルでは `start_end_flag=0` の試験状態記述子を出力します。放送運用上必要な前後の音声告知や、デジタル放送のPMT/TMCCの時間制御は生成しません。
- 日時フィールドは告示の別表コードを使い、偶数ブロックでは送出時刻に応じて前後の日・時へ切り替えます。
- 一度に生成できるブロック数は100までです。

出力した音声をアプリ内またはスピーカーで再生すると、近くのEWS対応受信機が反応する場合があります。このアプリには電波送信機能はありません。信号は学習・ローカル検証用で、放送設備や受信機の適合性を保証しません。

符号配置は[告示第405号（総務省 電波法令検索）](https://www.tele.soumu.go.jp/horei/law_honbun/72103000.html)に、変調条件は[無線設備規則第9条の3](https://www.tele.soumu.go.jp/horei/law_honbun/72081000.html)に基づきます。調査内容は[仕様メモ](./緊急警報放送_EWS仕様と運用.md)を参照してください。
